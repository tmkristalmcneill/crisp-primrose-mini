# crisp-primrose-mini

Engineering manager · release engineering · notes in public

## 用法

```bash
cat data.txt | cargo run
```

```

```

## 安装

```bash
git clone https://github.com/USER/crisp-primrose-mini.git
cd crisp-primrose-mini
cargo build --release
```
